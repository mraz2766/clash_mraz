# Windows 2.6.2 视觉与交互

参考本仓库 `clash-mac` 分支 `4a1f5a37`（2.9.7），以 Windows main 的业务实现为基础，逐页移植前端。保持 React 19、MUI、Emotion、SCSS、Tauri 与既有数据 hooks。

## 主题与窗口

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 工作区 | #F5F5F7 | #202023 |
| 内容表面 | #FFFFFF | #2C2C2F |
| 强调色（主操作、开关、选中竖条、进度） | #005FB8 | #60CDFF |
| 主要文字 | #292929 | #F3F3F3 |
| 柔和边线 | #EAEAEA | #3B3B3B |
| Hover 叠加 | rgba(0,0,0,.037) | rgba(255,255,255,.061) |
| 选中叠加 | rgba(0,0,0,.055) | rgba(255,255,255,.083) |

强调色只用于选中、开启和主操作，正文与图标保持中性灰。状态背景为半透明叠加，保证静止 < Hover < 选中。流量上下行在侧栏、指标与图表中统一使用流量配色偏好。

主题由 `src/pages/_theme.tsx` 统一提供，布局位于 `src/assets/styles/workspace.scss`，语义组件读取既有 `--md-*` 变量。Windows 字体优先 Segoe UI Variable、Segoe UI，随后回退系统字体；不打包 SF Pro。

侧栏宽 218px、导航行约 36px。控件圆角 6px，卡片默认 14px；表面使用细描边、轻微顶部高光与两层低透明度阴影。统一读取 `--surface-card-bg`、`--surface-card-border`、`--surface-card-shadow` 等变量，深色模式单独调整边缘与投影。背景保持实色，不做背景模糊。字号收敛为 12/13/14/20/28 五档，标题字重 600。遵循减少动态效果，虚拟列表滚动不逐行播放动画。

保留 Windows 标题栏与原生窗口控制，侧栏不预留 Traffic Light 空间。自定义标题栏仍遵循原有窗口装饰设置。Mac 分支保持独立。

列表页（代理、订阅、连接、规则、日志）与页头共用 24px 左右边距，工具栏、列表和表格左缘对齐标题。代理组标题、连接表格使用带柔和描边的内容表面。批量或破坏性操作（关闭全部连接、清除日志）使用标准按钮，强调色只留给每屏一个主操作。空状态统一为小号线框图标加一行次要文字。

## 动效

动效由 [Motion](https://motion.dev/) 提供，通过 `LazyMotion` 按需加载布局动画功能，`MotionConfig reducedMotion="user"` 跟随系统“减少动态效果”。弹簧参数集中在 `src/lib/motion.ts` 的 `springs`：`snappy` 用于选中块与指示器，`gentle` 用于面板与卡片进场，`number` 用于数字过渡；只快速收敛、不回弹摇摆。退出动画统一约 120ms，比进场更快。

- 分段控件（`SegmentedControl`）与侧栏导航共用一个随选中项滑动的表面块（`layoutId`）。
- 首页分区挂载时依次上浮淡入（`Reveal`），间隔约 45ms；诊断区展开、收起时高度平滑变化。
- 实时速度与内存用 `AnimatedNumber` 连续过渡，逐帧直接写入 DOM，不触发 React 重渲染；单位变化时直接跳到新值。
- 通知从所在边缘滑入，其余通知随之重排，可左右滑动关闭。
- 命令面板（Ctrl+K）首次打开时才加载，高亮行在选项间滑动。
- 虚拟列表的行不做进场动画，避免滚动时逐行播放。

## 页面结构

应用内 Logo 默认隐藏，在“设置 → 外观 → 显示 Logo”中启用。侧栏和 Windows 标题栏的小图标共同遵循该开关。偏好保存到前端本地；隐藏后保留 Clash 名称和版本，折叠侧栏不留空品牌区。标题栏只替换小图标，不改变原生窗口控制、应用大图标、托盘与安装器资源。

订阅卡片采用自适应网格，单个订阅不再拉满整行。标题与当前使用状态同行，压缩内边距与进度条；流量、更新时间、到期信息和原有操作均保留。连接、规则和日志只给整个列表增加表面层次，不为每行增加阴影。

首页依次为连接/模式控制、实时指标、趋势与关注组、订阅信息、折叠诊断。内容宽度不足 740px 时关注组优先单列显示，控制栏在窄尺寸下换行。诊断组件展开时才挂载，不在启动时主动测试网站。

代理列表保留选中、固定节点、延迟和切换中状态；更多操作菜单收纳搜索、排序、节点定位、测速地址与详情开关。分组跳转明确点击后执行。

设置按通用、外观、网络、备份、高级分类。搜索跨分类且忽略大小写；空结果不保留空分区标题；弹窗宿主独立于搜索结果，避免切换分类丢失对话框状态。Windows UWP 工具仍在网络分类。

网站出口查看只筛选当前活动/近期连接，不修改规则，不发起网站请求；没有记录不能推断为直连。流量图配色为本地前端偏好，默认低饱和彩色，不修改 verge.yaml 或 Mihomo 配置格式。

## 性能约定

- 轮询以窗口可见性为准：WebView 在窗口隐藏到托盘后仍可能报告页面可见，因此由共享的可见性状态（`src/hooks/use-visibility.ts`）统一判断，SWR 定时刷新在不可见时跳过。
- 全局数据提供者只保留代理视图、内核配置、系统代理与运行状态；规则、规则 Provider 与运行时长由使用它们的页面或卡片按需拉取。
- 首页以外的页面按需加载，并在启动空闲后预取，入口包约为此前的 58%。
- 首页的指标行与流量卡片各自只订阅需要的数据；侧栏速度读数在首页隐藏，避免同一数据三处重复渲染。
- 不对实色背景使用 `backdrop-filter`，避免每秒刷新流量时重复合成模糊层。

## 兼容边界

保留 main 的系统代理就绪检查与首次启动等待。Mac 分支的测速 URL、自动组检测、DNS、服务、更新和打包裁剪均不随界面移植。保留用户自定义主题与托盘图标的优先级。

键盘支持 Ctrl+K、Ctrl+,、Ctrl+1–8、Ctrl+B；输入框、编辑器和弹窗内不抢占。图表关闭后仍显示实时指标与累计流量。
