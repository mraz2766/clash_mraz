# Clash for Mac 使用说明

## 日常使用

- **订阅**：添加远程订阅或本地配置，选中要使用的 Profile。更新按钮刷新订阅内容。
- **代理**：展开分组并选择节点；延迟测试是辅助操作，不会因界面动画改变测试方式。节点右侧显示延迟或当前状态。
- **连接**：使用表格查看主机、IP、协议、规则、代理链和流量。保留搜索、排序与原有连接操作。
- **规则**：以紧凑列表查看规则类型、匹配内容和策略。
- **设置**：按需调整外观、语言、系统代理、TUN 和其他原有功能。

## 首页与设置

首页展示“关注的代理组”，其当前节点不代表所有网站的出口。“检查网站出口”按域名筛选 Clash 的活动及近期连接，显示匹配规则和代理链；需要先访问网站产生连接，未捕获连接不能推断直连。

实时指标独立显示，窄窗口自动将关注组置于图表之前。首页不重复显示侧栏小图表。

设置分为通用、外观、网络、备份、高级；输入关键词会搜索所有分类，清空后恢复当前分类。代理组“更多操作”提供搜索、排序、定位和测速地址；“跳转代理组”通过明确点击定位，不因鼠标经过而跳转。

订阅显示当前使用状态、剩余流量和到期时间；更新成功会短暂显示勾选。高级覆写与脚本折叠保留，展开后仍可编辑。

## Mac 快捷键

- `⌘,`：打开设置。
- `⌘1–8`：按侧栏顺序切换页面。
- `⌘B`：折叠或展开侧栏，也可点击侧栏顶部按钮。
- 原生红黄绿按钮控制关闭窗口、最小化与全屏。

## 状态颜色

中性深灰与浅灰选中底表示主要操作或当前选中；绿色表示成功或较快延迟；黄色表示警告或中等延迟；红色表示错误或较慢延迟；灰色表示未知或尚未测速。实际失败、超时判断沿用原有业务逻辑。

## 外观与无障碍

支持浅色、深色及原有主题设置。优先使用 macOS 系统字体，没有下载或打包 SF Pro。

系统开启“减少动态效果”后，界面的位移和缩放会关闭，按钮和列表依然立即响应。窗口拖拽、缩放、最大化与最小化沿用原实现。

## 常见问题

**安装包在哪里？** 应用位于 `/Applications/Clash for Mac.app`，带版本号的 ZIP 位于 `releases/`，构建结束会输出完整路径。

**为什么内部仍能看到 clash-verge？** 核心可执行文件与系统服务保留兼容原名。2.7.0 的 Bundle ID 与配置目录已经独立为 `io.github.mraz.clash.mac`。

**能否与上游版本同时运行？** 配置已隔离，底层服务与代理端口仍可能冲突。请先退出另一个代理客户端。

**为何更新后界面恢复原版？** Mac 分支已移除上游应用自动更新模块，使用新的 Mac 应用包手动更新。若被其他版本覆盖，请重新安装本分支构建的应用。

**为什么浏览器预览没有代理数据？** 真实数据来自 Tauri 与 Mihomo。日常运行请使用 Applications 中的桌面版本。

流量图默认使用低饱和蓝色（下载）与青绿色（上传）。在「设置 → 外观」选择单色或低饱和彩色，也可关闭流量图；关闭后保留实时速度与累计流量，首页自动收紧。配色与开关保存在独立 Mac 配置中。
