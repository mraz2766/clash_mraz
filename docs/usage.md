# 使用说明

## 日常使用

- **订阅**：添加远程订阅或本地配置，选中要使用的 Profile。更新按钮刷新订阅内容。
- **代理**：展开分组并选择节点；延迟测试是辅助操作，不会因界面动画改变测试方式。节点右侧显示延迟或当前状态。
- **连接**：使用表格查看主机、IP、协议、规则、代理链和流量。保留搜索、排序与原有连接操作。
- **规则**：以紧凑列表查看规则类型、匹配内容和策略。
- **设置**：按需调整外观、语言、系统代理、TUN 和其他原有功能。

## 状态颜色

蓝色表示主要操作或当前选中；绿色表示成功或较快延迟；黄色表示警告或中等延迟；红色表示错误或较慢延迟；灰色表示未知或尚未测速。实际失败、超时判断沿用原有业务逻辑。

## 外观与无障碍

支持浅色、深色及原有主题设置。Windows 优先使用 Segoe UI Variable / Segoe UI，macOS 回退到系统字体。没有下载或打包 SF Pro。

系统开启“减少动态效果”后，界面的位移和缩放会关闭，按钮和列表依然立即响应。窗口拖拽、缩放、最大化与最小化沿用原实现。

## 常见问题

**安装包在哪里？** 本地构建的可分发 EXE 位于 `releases/`，构建结束会输出完整路径。

**为什么内部仍能看到 clash-verge？** 配置目录、核心可执行文件、系统服务和历史兼容标识保留原名，以免破坏已有数据和服务。

**能否与上游版本同时运行？** 两者保留了相同的内部服务和配置标识，不能视作完全隔离的两个应用。请先退出另一个实例。

**为何更新后界面恢复原版？** 自动更新配置仍属于上游。本分支目前使用自己的安装包手动更新，自有更新签名发布流程尚未建立。

**为什么浏览器预览没有代理数据？** 真实数据来自 Tauri 与 Mihomo。文档截图使用明确标注的演示数据；日常运行请使用桌面版本。
